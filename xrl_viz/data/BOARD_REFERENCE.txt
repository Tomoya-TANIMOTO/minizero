1. 座標とインデックスの対応
------------------------------------------------------------------------------
  tree_json のノードは row / col を 0 起点で持つ。cell 名との対応は

      cell 名 = chr('A' + col) + str(row + 1)
      col: A=0 B=1 C=2 D=3 E=4 F=5 G=6 H=7
      row: 0 が rank 1、7 が rank 8
      action_id = row * 8 + col        （例 F3 -> row 2, col 5, id 21）

  board は board[row][col] の入れ子配列。console.cpp の boardToJson が
  row を 0 から回して出しているので、JSON の先頭の行が rank 1。
